# 📖 [Smart Campus Resource Booking System] <a name="about-project"></a>

> A centralized desktop application developed in Python to streamline shared academic resource management across Richfield Graduate Institute campuses. It replaces manual booking methods to eliminate scheduling conflicts, enforce campus policies, and provide management with real-time usage analytics.

### Tech Stack <a name="tech-stack"></a>

> Language: Python 3

> GUI Framework: Tkinter / ttk

> Database: SQLite3


<!-- Features -->

### Key Features <a name="key-features"></a>

- **[key_feature_1]**

  > Role-Based Workspaces: Dedicated interfaces for Lecturers (booking management), Campus Administrators (resource management), and System Operators (cross-campus reporting).

- **[key_feature_2]**
  
  > Collision Detection & Policy Enforcement: Automated overlap prevention for time slots and campus-specific booking duration limits.

- **[key_feature_3]**

  > Persistent Data Storage: Relational SQLite database utilizing UNIQUE constraints to maintain inventory and booking records without duplication.

## 💻 Getting Started <a name="getting-started"></a>


To get a local copy up and running, follow these steps.

### Prerequisites

In order to run this project you need:

> Python 3.x installed on your system.

> Standard Python libraries: sqlite3, tkinter, ttk, datetime (all included with default Python installations).

### Setup

Clone this repository to your desired folder:

> cd my-folder
> git clone https://github.com/shuhad786/smart-campus-booking.git
> cd smart-campus-booking

### Usage

To run the project, execute the following command:

> Bash
> python main.py
